#作品名称
停车场出口智能抬杆系统

##1.功能概述
这个系统有三种控制杆子闭合状态的方式：（1）利用超声波模块测距自动开关门   （2）利用手动开关门的按键控制  （3）通过电脑串口助手输入0或1控制开闭状态，输入a则切换至自动模式 ，以及有用于判断此时为自动模式还是手动模式的提示灯。（4）若系统处于自动模式，此时用按键或者用串口控制杆子开闭，则切换到手动模式

##4.实现思路
系统框图：看文件夹中的系统框图文件
主循环：进入主循环
    │
是否距离上次测距已满约100ms？
    ├─ 是：US_ReadDistance()，更新距离
    └─ 否：保留上次距离
    │
Garage_Task()
自动模式下，根据距离决定开门或延时关门
    │
UI_Task()
处理手动按键，更新红绿灯和模式灯
    │
Servo_Task()
根据 gate_open 设置舵机位置指令
    │
UART_Task()
每隔约500ms，发送距离、模式和目标状态
    │
HAL_Delay(10)
    │
    └──────── 回到主循环开始

串口指令：电脑端输入1则闸杆开，输入0则闸杆关，输入a则重新切换到自动模式

##6.遇到的问题与解决
（1）舵机开合角度过小    解决方法：将打开和关闭位置的脉宽差值增大
（2）舵机抖动           解决方法：使用更稳定的外部5V电源給舵机供电
（3）无法直接判断系统此时是自动模式还是手动模式      解决方法：加一个蓝色的指示灯，自动模式的时候亮起

##8.演示说明
上电后将物体靠近超声波测距模块，可以发现舵机旋转至开启状态，指示灯由红变亮，此时用于检测自动状态的蓝色指示灯亮起。接下来操纵开关按键，闸杆可以正常开闭。此时退出自动模式，蓝色指示灯熄灭。打开电脑端的串口助手，发送0和1，闸杆可以正常开闭。再向串口助手发送"a"，此时系统切换为自动模式，蓝色指示灯再次亮起。
